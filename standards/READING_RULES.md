# 经典研读室 · 网站呈现规则

1. 首次进入显示空书架及 JSON 导入入口。按经典归集，每个注本和修订本独立列出，可直接打开。测试样例仅用于验证。
2. 一次导入一个版本。校验和保存均成功后直接入架。失败时保留原书架并显示具体原因。
3. 阅读页展示当前底本、章节、原文和所选注本。章节依据底本顺序导航。同底本切换注本或增选对读注本时保留章节。
4. 原文正文靠左对齐，短句和折行后的文字也沿左侧排版。保留底本的段落与换行，一段原文在阅读区只显示一次。
   - 右栏以当前章为阅读单位。每位注家的每个所选注本各占一节，节首标明注家与注本；同一注本有多个所选修订版时，以修订号区分。
   - 节内按顺序连续呈现该注家在本章的注文，保留注文自身的分段。每节只设一次注家与注本标题，逐句引文、句号编号或“注／疏”等标签均不自动生成为逐条小标题。
   - 同一条注文即使解释多个词句，在该版本的全章对读区也只出现一次。读者可通过原文彩线查看具体词句所对应的注疏。
5. 原文下方为各个所选注本绘制不同颜色、不同高度的标注线，并附作者与注本图例。悬停、点击、轻触或用键盘激活某条彩线，即在原文旁显示该注本在该处的注文。注疏正文只供阅读。命中和排序细则见[注疏标注与显示规则](ANNOTATION_RULES.md)。
6. 本地验收使用独立的空书架。正式发布前另行决定共用书架的存储位置、访问范围及部署方式。
7. 书架和选本处在注本名、修订号旁列出已知的作者与时代。阅读页可查看当前原文的底本出处和各注本的文献出处。底本出处依原文单元关联的来源展示；注本出处使用注本所载书名及可明确对应的来源记录。有来源链接时可直接打开，只有文字出处时显示文字，缺失的信息不作推断。
8. 本章有今译时，在原文下方单列「今译」，进入章节时默认展开，读者可手动收起或再次展开。本章无今译时省略该区域。
9. 主读注本 1.1.0 另有已生成且未标为待修订的章节辅助译文时，原文下方单列「AI今译」，默认展开，可收起。显示生成服务、已知模型和人工复核状态。草稿与待修订条目保留于数据中。该区独立于底本所附「今译」、原文彩线和全章注疏。
