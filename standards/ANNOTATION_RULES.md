# 原文锚点与注文显示规则

1. annotations[].target_refs 指明一条注疏实际解释的对象，支持经文片段、整条注文、注文片段和章节。display_groups 单独记录读者在原文上进入这一组注疏的位置。例如疏解释一条注，二者可以共用同一处原文入口。
2. `inline` 锚点绑定 `text_id`。`start_offset` 从 0 起，`end_offset` 为不含的终点，单位为 UTF-16 码元。标点和换行均计入，不能切开代理对。`anchor_text` 必须逐字等于原文切片，`occurrence` 从 1 起，`context_before` 与 `context_after` 须与紧邻文字吻合。
3. 只在原文下方绘制注疏彩线。同一处原文关联多版时，各版彩线分层排列，图例标出颜色对应的作者与注本。彩线遇标点断开，随原文折行；同一锚点被分成多个可见线段时，各段仍关联同一锚点。
4. 激活彩线后，以该线所属的注本和触发处的原文位置确定命中组。同一注本的长短锚点重叠时，点击重叠处可见两组；点击仅被长锚点覆盖的位置只见长锚点对应的组。多个命中组按文件中 `display_groups` 的数组次序呈现，每组 `entries` 按显式 `display_order` 升序排列，组内顺序值不可重复。同一组有多个锚点命中时只呈现一次。`section` 组用于章级注文。
5. 鼠标悬停、点击、触屏轻触或键盘激活彩线时，在触发位置旁打开浮窗，保留原文阅读位置。指针移入浮窗后可继续阅读。支持关闭及 Escape；用键盘关闭后，焦点回到触发彩线。
6. 跨句注文录入一次，可用一个完整范围或多个精确锚点绑定。右栏按章汇集各所选注本的注文，依注家与注本分节。署名取注文所载作者，缺省时沿用注本作者。同一版本同一章按 `annotation_id` 去重；各节内部按本章各组在文件中的次序及组内显式次序连续排文，保留原有分段。词句锚点用于定位浮窗，不据此拆分右栏或添加逐句标题。无注处留空。注疏正文只供阅读。
7. 翻译单元在原文下方单列为「今译」，默认展开，可收起。行内入口应绑定原文单元；引用其他注文的学术关系写入 `target_refs`。
8. 章节 AI 今译专存于顶层 `ai_translations`。其来源快照用于核对译文所据经文，不产生行内入口、直接解释对象或弹窗条目。
