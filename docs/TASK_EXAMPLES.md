# 如何使用任务配置

配置是编辑委托单，位于 `task-configs/`。其中的书名、版本、范围及待核事项供制作者使用。导入书架时提交依契约生成的注本 JSON。

## 《中庸章句》全本任务

采用[朱熹配置](../task-configs/zhongyong-zhu-xi.json)。若取得的材料只有三十三章和篇首总说，先把独立序文列为缺项。可制作明确标为节选的版本；全本须补齐并核对序文。对于同时有整句释义和一字训释的一句，经文设一个整句入口，分别记录两条注文，弹窗先句注后字注。章末总括用章级入口。该章 AI 今译从本版经文逐段生成，归入本章辅助阅读层。

## 《四书训义》任务

采用[王夫之配置](../task-configs/zhongyong-wang-fuzhi.json)。取得底本后先确定卷次和段落，再判断训义是通论一章、解释经文，还是解释前注。连续论说保留完整段落，按实际对象建立关联。

## 其他经典

复制[空白任务配置](../task-configs/template.json)，用该版本的分篇、卷次或品次填写章法。若为集解，核对每条引说的责任者；若为注疏合刻本，以疏直接解释的经文或注文为对象。先填写[注本模板](../templates/edition.json)里的版本、底本和正文。该模板是空白草稿，填入可阅读正文后才能通过导入校验。完整的数据形状可参照[两章 AI 今译示例](../standards/fixtures/ai-chapters.json)。
